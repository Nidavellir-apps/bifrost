# Bifrost

Public site for Nidavellir apps, served by GitHub Pages: privacy policies, support page, and `app-ads.txt`.

- `privacy/_template/` — the release loop (L5) copies this to `privacy/<slug>/` and fills `{{APP_NAME}}`, `{{DATE}}`, `{{COMPANY}}`.
- `app-ads.txt` — must be at the root of the developer website listed in the stores for AdMob verification.

The policy template is a starting point and needs review before the first app ships.
